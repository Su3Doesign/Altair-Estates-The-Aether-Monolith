# Distribution strategy

Start with Blender-native architectural products and tree species packs. Use the public catalogue as the stable product reference and link to whichever stores actually approve each product. Do not assume that one store's acceptance establishes eligibility on another.

The following is a channel-fit hypothesis, not a verified eligibility table or a sales forecast. Current terms, fees, tool restrictions, supported seller countries and payout methods must be checked in the official seller portal before submission; external policy pages were not accessible in this cloud session.

| Channel | Potential fit | Verify before listing |
| --- | --- | --- |
| [Fab](https://www.fab.com/) | Cinematic assets; later, tested native Unreal packages | Current AI declaration rules, accepted file/category requirements, seller/payout eligibility, third-party-content rules |
| [Superhive](https://superhivemarket.com/) | Blender-native products, procedural controls and workflow value | Current AI-assisted/generated product acceptance; do not assume a coding-assisted asset is accepted |
| [CGTrader](https://www.cgtrader.com/) | Standalone 3D architectural objects and vegetation | Seller verification, native-format expectations, licence terms and disclosure requirements |
| [TurboSquid](https://www.turbosquid.com/) | Production 3D models | Current AI content policy and technical requirements; do not promise certification or eligibility |
| [Gumroad](https://gumroad.com/) / direct sales | Native Blender packs with control demos and detailed support | Supported seller country/payouts, prohibited-product rules, taxes/refunds, hosting limits and selected customer licence |
| [itch.io](https://itch.io/) | Smaller asset packs and prototype use | Current creator rules/disclosures and whether the product's audience is a match |

## Pricing experiments

These are proposed USD launch prices, not appraisals:

- Cedar gatehouse: $39; glass pavilion: $39; courtyard arch: $29.
- Each tree species, three variants: $19. Consider a six-species bundle only after all variants pass close-up review.
- Mansion: $149 and estate: $249 are planning targets, not active offers. Reassess after native scene and visual QA; Unreal support would need a separate tested deliverable.
- Include camera setups with the scenes. Do not sell a camera-position JSON file as if it were a complete animated cinematic.

One small release is the best first demand test. Give a representative package to several intended users under explicit evaluation terms, observe whether they can append and use it without help, then tune the listing and price. The catalogue has no fabricated ratings, buyer counts or purchase buttons.

## Listing evidence

Use native renders from the actual delivery file, a plain asset overview, a gate/wind demonstration, and close-up wireframe/material views. Identify all staged props that are not included. The current catalogue uses no vehicles. If vehicles are added to later advertising, confirm commercial render rights and say they are not included.

Keep thumbnails consistent, show sizes and base geometry counts, and describe the intended use as cinematic visualization unless game or simulation functionality has actually been tested. Do not describe an upscaled preview as proof of native asset detail.

Preserve required licence/attribution notices. Apply each store's disclosure rules accurately; the catalogue can foreground design and art direction without making false claims about the tools used.
